## About this site

The whole site is a single `index.html` — CSS, JavaScript and all 31 product screenshots
(embedded as base64 JPEGs) live inside that one file. No framework, no build step, no
separate assets directory. Drop the file anywhere and it works, offline included.

To update the site, replace `index.html` and push. GitHub Pages serves it from the
default branch root.
